## Findings

**F1 — §5 errors (blocking).** Spec: "Every 4xx and 5xx response carries this body:
`{ "error": { "code": ..., "message": ... } }`" and "Requests must not produce 5xx responses,
including under concurrent load."
Observed: `HEAD` and `OPTIONS` on any path return `501 Unsupported method` with a
`text/html` body; a malformed request line returns the stdlib HTML `400 Bad request syntax`.
Expected: a 4xx (e.g. 405 `method_not_allowed`, as for DELETE) with the JSON envelope, never 5xx.
Cause: `Handler` only maps GET/POST/PUT/PATCH/DELETE; `BaseHTTPRequestHandler.send_error`
is not overridden.
Reproduce:
```sh
curl -s -i -I localhost:18400/health            # HTTP/1.1 501, text/html
curl -s -i -X OPTIONS localhost:18400/health    # HTTP/1.1 501, HTML body
curl -s -i -X 'GET GET' localhost:18400/health  # HTTP/1.1 400, HTML body
```
